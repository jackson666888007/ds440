# Figure and Table Reproduction Guide

This document explains how every figure/table used in the DS440 final paper can be reproduced from the project code.

## Main command

Run the full analysis from the repository root:

```bash
pip install -r requirements.txt
python src/ds440_final_analysis.py
```

In Jupyter or Google Colab:

```python
!python src/ds440_final_analysis.py
```

The script writes figures to:

```text
outputs/figures/
```

and tables to:

```text
outputs/tables/
```

## Data files used by the script

### IMDb baseline files

The script downloads these automatically from IMDb's public non-commercial dataset page:

- `title.basics.tsv.gz`
- `title.ratings.tsv.gz`
- optional: `title.principals.tsv.gz`
- optional: `name.basics.tsv.gz`

IMDb dataset page:

https://developer.imdb.com/non-commercial-datasets/

### Optional revenue file

For the revenue regression and star-power extension, place this file in the repository:

```text
data/box_office.csv
```

Supported format:

```csv
primaryTitle,startYear,revenue
Avatar,2009,2787965087
```

or:

```csv
tconst,revenue
tt0499549,2787965087
```

## Figure mapping

### Figure 1: Dataset scale across filtering steps

Output file:

```text
outputs/figures/fig1_dataset_scale.png
```

Generated by:

```python
plot_dataset_scale(scale)
```

Input table:

```text
outputs/tables/dataset_scale.csv
```

Purpose in paper:

Shows how the project moves from raw IMDb title/rating files into the filtered movie-level baseline and high-vote robustness subset.

```text

```

## Important limitation

The IMDb baseline results are reproducible from official IMDb public datasets. The revenue and star-power results depend on the availability and quality of the external `box_office.csv` file. Because the revenue extension may use title-year matching rather than IMDb IDs, those results should be interpreted as matched-subset results.

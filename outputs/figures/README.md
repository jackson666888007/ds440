# Generated figures

This folder is reserved for figures generated by the analysis script.

Run the project from the repository root:

```bash
python src/ds440_final_analysis.py
```

The script will generate PNG files here, including:

- `fig1_dataset_scale.png`
- `fig2_vote_distribution.png`
- `fig3_vote_concentration.png`
- `fig4_rating_by_genre_decade.png`
- `fig5_key_coefficients.png` if `data/box_office.csv` is available
- `fig6_ablation_r2.png` if both revenue and star-power data are available

For GitHub preview, this repository also includes SVG versions of the final-report figures in this folder. The SVG files are lightweight and can be viewed directly in GitHub.
